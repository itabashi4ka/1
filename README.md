# 分割払い計算

分割払いの条件を計算し、患者に見せながら説明するための**Webアプリ**です（ブラウザで動きます）。
計算結果は自作のHTMLテンプレートで「お支払い予定表」として印刷・PDF保存できます。

- Mac（Safari / Chrome）と iPad（Safari）で使えます。インストールや Xcode は不要です。
- 通信は一切しません。患者名などの入力内容は保存されず、ページを閉じる・再読み込みすると消えます。
- 保存されるのは設定（院名・ロゴ・既定の年率・テンプレートなど）だけで、そのブラウザの中に保存されます。

仕様は [`docs/spec.md`](docs/spec.md)、実装上の決めごとは [`CLAUDE.md`](CLAUDE.md) を参照してください。

## 使い始める

### Mac

1. `dist/installment-calculator.html` をダウンロードして、好きな場所（例: 書類フォルダ）に置きます。
2. ダブルクリックするとブラウザで開きます。Dock やブックマークに登録しておくと便利です。

> 設定は「そのブラウザ × そのファイルの場所」ごとに保存されます。ファイルを移動したり、別のブラウザで開いたりした場合は、
> 設定画面の「設定を書き出す／読み込む」で移してください。

### iPad

iPad の Safari はダウンロードしたHTMLファイルを直接アプリのように開けないため、**https のアドレスで公開**して開きます。
公開しても、計算や入力内容がサーバーに送られることはありません（ページのファイルを配るだけです）。

1. `web/` フォルダを静的ホスティングに置きます。無料で使える例:
   - **GitHub Pages**（このリポジトリの Settings → Pages で `web/` を公開。非公開リポジトリでは有料プランが必要）
   - **Netlify Drop**（https://app.netlify.com/drop に `web` フォルダをドラッグするだけ）
   - **Cloudflare Pages**
2. iPad の Safari で公開したアドレスを開き、共有ボタン →「ホーム画面に追加」。
   ホーム画面のアイコンから全画面で起動でき、一度開けばオフラインでも使えます。
3. Mac で「設定を書き出す」したファイルを AirDrop などで iPad に送り、設定画面の「設定を読み込む…」で取り込むと同じ設定になります。

同じ公開アドレスを Mac のブラウザで開いて使ってもかまいません。

## 使い方

1. 計算モードを選ぶ（① 月額から回数を求める／② 回数から月額を求める）
2. 支払総額・年率・分割回数（または月額）を入れる。入力するとすぐ計算されます（全角数字・カンマも可）
3. 必要ならボーナス払い（加算額・月）、初回支払月、患者名を入れる
4. 結果は大きく表示されます。利息総額は伏せてあり、「利息総額を表示」で表示されます
   （入力を変えて結果が変わると自動で伏せ直します）
5. 「支払い表を出力」でテンプレートと利息の表示有無を選び、プレビューを確認して「印刷 / PDFで保存」
   - Mac: 印刷画面の「PDF」→「PDFとして保存」（Chrome は送信先「PDFに保存」）
   - iPad: 印刷画面で AirPrint のプリンタを選ぶ。PDFにするときは印刷画面の共有ボタン →「"ファイル"に保存」
6. 次の患者に移るときは「入力をクリア」

年率欄は起動時に設定の「既定の年率」が入ります。別の値にしたときは注意表示が出ます。
「この値を既定にする」を押したときだけ既定値が更新されます。

## 設定

右上の「設定」から開きます。変更はすぐ保存されます。

- 院名、ロゴ画像（PNG/JPEG、800KBまで）、テーマカラー、強調色、フォント、文字サイズ
- 注記文、利息を伏せるときの表示
- 端数処理（切り捨て／切り上げ／四捨五入）、差額の調整（最終回／初回）
- 既定の年率、ボーナス月の初期値
- 使用するテンプレート、テンプレートの読み込み・削除
- 設定の書き出し・読み込み・初期化

ブラウザの「履歴とWebサイトデータを消去」を行うと設定も消えます。**設定を変えたら「設定を書き出す」でファイルを保存しておく**と安心です。

## 支払い表テンプレート

設定画面の「既定のテンプレートをダウンロード」で `default.html` を取り出し、テキストエディタで編集して
「テンプレートを読み込む…」で追加します。読み込んだテンプレートは設定に含まれ、書き出し／読み込みで一緒に移せます。

### プレースホルダー

金額はカンマ区切りの数字だけが入ります（「円」はテンプレート側で書いてください）。値はHTMLエスケープされます。

| プレースホルダー | 内容 |
|---|---|
| `{{clinic_name}}` | 院名 |
| `{{patient_name}}` | 患者名 |
| `{{issue_date}}` | 作成日（2026年9月30日） |
| `{{principal}}` | 支払総額（元本） |
| `{{annual_rate}}` | 年率（3、2.5 など） |
| `{{installments}}` | 分割回数 |
| `{{monthly_payment}}` | 月額（ボーナスを除く通常回の額） |
| `{{first_payment}}` / `{{last_payment}}` | 初回／最終回の支払額 |
| `{{first_month}}` / `{{last_month}}` | 初回／最終回の支払月 |
| `{{bonus_amount}}` | ボーナス加算額 |
| `{{bonus_months}}` | ボーナス月（6月・12月） |
| `{{total_bonus}}` | ボーナス加算の合計 |
| `{{total_payment}}` | 総支払額 |
| `{{total_interest}}` | 利息総額（「利息を表示する」を選んだときだけ） |
| `{{note}}` | 注記文 |
| `{{theme_color}}` / `{{accent_color}}` | テーマカラー／強調色（#RRGGBB） |
| `{{font_family}}` | 設定のフォント名 |
| `{{logo}}` | ロゴ画像（`<img src="{{logo}}">` で使う） |

### スケジュール表の繰り返し行

`<!-- ROW_START -->` と `<!-- ROW_END -->` で1行分のひな形を囲むと、回数分だけ複製されます。

```html
<!-- ROW_START -->
<tr>
  <td>{{row.no}}</td>
  <td>{{row.month}}</td>
  <td>{{row.payment}}</td>
  <td data-show="bonus">{{row.bonus}}</td>
  <td>{{row.principal}}</td>
  <td data-show="interest">{{row.interest}}</td>
  <td>{{row.balance}}</td>
</tr>
<!-- ROW_END -->
```

### 表示の切り替え（data-show）

`data-show` 属性を付けた要素は、条件に合わないとき要素ごと取り除かれます。

| 属性 | 取り除かれる条件 |
|---|---|
| `data-show="interest"` | 出力時に「利息を表示する」を選ばなかったとき |
| `data-show="bonus"` | ボーナス払いが無いとき |
| `data-show="logo"` | ロゴ画像が設定されていないとき |
| `data-show="patient"` | 患者名が空のとき |

用紙の大きさや余白は、テンプレートの CSS の `@page { size: A4; margin: ... }` で指定します。

## 開発

```sh
npm test         # 計算・設定・テンプレートのテスト（Node.js 20 以上）
npm run build    # web/ を1ファイルにまとめて dist/installment-calculator.html を作る
```

`web/index.html` はビルドなしでそのまま開いて動作確認できます。

## 未確定事項・注意

- 実際の分割条件は信販会社の計算方法（手数料率表など）と一致しない場合があります。画面と支払い表には必ず「目安」である旨の注記を入れてください（設定の注記文）。
- 設定の Mac・iPad 間の自動同期はありません。設定の書き出し／読み込みで移してください。
